## 📖 About

**Ae2 Sable Wireless Fix** is a small compatibility mod for [Applied Energistics 2](https://www.curseforge.com/minecraft/mc-mods/applied-energistics-2) and [Sable](https://www.curseforge.com/minecraft/mc-mods/sable).

It addresses a compatibility issue that can occur when using AE2's wireless terminals with blocks located inside Sable's physics-based sublevels.

**AE2 in Sublevels adjusts the wireless signal distance calculation to account for Sable's sublevel transformations.**

## ✨ Features

- **Sable sublevel compatibility** — Adjusts AE2 wireless distance handling for access points located inside recognized Sable sublevels.
- **Preserves normal AE2 behavior** — Access points outside the relevant Sable sublevels continue through AE2's original distance-checking logic.
- **Lightweight compatibility patch** — No new items, blocks or machines.
- **Focused functionality** — Designed to address the wireless range issue without replacing AE2's wireless terminal system.

## 📦 Requirements

The mod requires the following mods:

- **Applied Energistics 2 (AE2) 19.2.x**
- **Sable 2.0.x**

Other versions have not necessarily been tested. Compatibility depends on the relevant AE2 and Sable APIs remaining compatible.
